## Analytical framework

The active v2 pipeline used across new work is:

`ROUTER -> SCOUT -> SOURCEGRID -> K-ALIGN -> IPR -> BLACKGLASS-I -> CRF -> COMMAND -> BLACKGLASS-II -> RECORD LOCK`

AAIK operates across the full pipeline. Luna, Terra, and Sol are the cognitive control plane. AURORA GRID is the complete operating system rather than a step within itself.

The framework emphasizes source provenance, explicit uncertainty, adversarial testing, binding constraints, gate-transition evidence, falsifiers, probabilities, decision utility, action-level red-teaming, revision conditions, and append-only outcome records.
