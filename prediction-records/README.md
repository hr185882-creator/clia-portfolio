# Prediction and Model-Audit Records

This directory preserves forecast exports, model-generated evaluations, and later adjudication records without silently converting submitted material into verified history.

## Record classes

- **Forecast log** — a submitted or recovered list of forecasts, tracked claims, outcomes and live items.
- **Model audit** — an assessment generated by an AI system about the user's forecasting or analytical performance.
- **Adjudication record** — a separate evidence-backed review that assigns final resolution states under the active AURORA GRID taxonomy.

## Provenance rule

Imported records retain the source system, date, supplied wording and known limitations. Statements such as `RIGHT`, `FAILED`, `VERIFIED`, `Tier-1`, `A-`, or `hit perfectly` remain claims of the originating record until independently adjudicated.

## Resolution taxonomy

- `RES-OPEN`
- `RES-HIT`
- `RES-PARTIAL`
- `RES-MISS`
- `RES-VOID`
